# Contributing

Thank you for helping improve this developer profile.

## Propose a change

Open an issue before making a substantial update. Explain the improvement,
which section it affects, and why it helps visitors understand the work more
clearly.

## Quality checklist

- Keep the change focused on one improvement.
- Confirm that every project, portfolio, and contact link works.
- Describe projects accurately without exaggerated claims.
- Preserve the concise structure and readable Markdown formatting.
- Do not include credentials, private data, or unpublished source material.

## Pull requests

Use a descriptive title and summarize the reason for the change. Link the
related issue when one exists, and keep unrelated edits in separate pull
requests so each contribution is easy to review.
